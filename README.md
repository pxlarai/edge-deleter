## 🛑 Edge Vanisher (Deep Removal)
Because Microsoft Edge is built into the system, a simple "Uninstall" button doesn't work. This script terminates all Edge processes, strips the Registry keys, and locks the folders so it cannot come back.

### 🚀 How to Run:
1. Right-click the **Start Button** and select **Terminal (Admin)** or **PowerShell (Admin)**.
2. Copy the entire code block for the `Edge_Vanisher` script.
3. **Paste** it into the blue/black PowerShell window.
4. Hit **Enter**.
5. Wait for the "Successfully deleted" messages and for **Explorer to restart**.

> **Note:** If you do not run PowerShell as an **Administrator**, the script will fail with "Access Denied" errors because it cannot touch system-protected files.
